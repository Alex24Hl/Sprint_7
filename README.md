# Sprint_7 - "Тестирование API"

## Структура проекта

1. **tests**: модуль содержащий следующие api-тесты:
   - **tests_create_courier.py** - тесты на ручку "Создать курьера"
   - **test_create_order.py** - тесты на ручку "Создать заказ"
   - **test_list_of_orders.py** - тесты на ручку получения списка заказов
   - **test_login_courier.py** - тесты на ручку "Логин курьера"

2. **helpers**: файл с дополнительными функциями:
   - **register_new_courier_and_return_login_password** - исходная функция для регистрации нового курьера
   - **delete_courier** - удаляет созданного курьера после теста
   - **create_test_order** - создание тестового заказа
   - **generate_random_strinп** - генерация случайной строки
3. **urls**: файл с ссылкой на документацию API "Яндекс Самоката" 
4. **allure_result**: модуль, где находятся результаты выполнения тестов
